# Project Charter

## Title
ASME-Aware Structural FEM Study of a Simplified Reactor-Internal Support Component Using ANSYS Mechanical and Python

## Purpose
This project demonstrates a junior-level structural verification workflow for a simplified reactor-internals-inspired support component.

## Scope
- Static structural analysis in ANSYS Mechanical
- Mechanical load cases
- Thermal expansion sensitivity case
- Mesh convergence study
- Simplified yield-based allowable stress screening
- Python post-processing of exported results
- Verification-style report

## Out of Scope
- ASME BPVC code compliance
- Certified nuclear component design
- Proprietary reactor geometry
- Fatigue, seismic, irradiation, weld, bolt preload and nonlinear plasticity qualification
