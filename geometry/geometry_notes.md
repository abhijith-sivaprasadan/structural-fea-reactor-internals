# Geometry Notes

## Improved Model

The improved model is a simplified reactor-internals-inspired guide/support component created for structural FEM portfolio demonstration.

## Geometry Features

- Rectangular support plate
- Raised central guide collar
- Central through-bore
- Four raised mounting bosses
- Four counterbored mounting holes
- Four radial stiffening ribs
- Filleted rib, boss, collar and plate edges

## Engineering Purpose

The central collar represents a reinforced guide/load-transfer region. The radial ribs provide simplified load paths from the central collar to the mounting regions. The mounting bosses and counterbores represent simplified bolted support locations.

## Disclaimer

This is a non-proprietary, reactor-internals-inspired support component created for portfolio demonstration. It is not based on Westinghouse geometry and does not represent a certified nuclear component.
